# SteamMachineFX-HollowKnight

A mod for Hollow Knight which interfaces with my [SteamMachineFX service](https://github.com/JordanOsterberg/SteamMachineFX-Installer) to control the Steam Machine LED based on in-game health.

Requires installation of SteamMachineFX, see the link above.

## Installation

1. Install BepInEx. This can be done by viewing [the GitHub repository](https://github.com/BepInEx/BepInEx) and/or by reading the [installation and first time setup guide](https://docs.bepinex.dev/articles/user_guide/installation/index.html). 
> This mod was developed using BepInEx `5.4.23.5`, but should work on future versions provided the API scope doesn't change.

2. Install the mod DLL (which can be downloaded from the GitHub releases) to the BepInEx plugins folder. For Steam Machine, this path is `/home/deck/.steam/steam/steamapps/common/Hollow Knight/BepInEx/plugins`.

You can now play the game and the LED strip should display your health.
